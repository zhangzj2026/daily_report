二、分券商观点详录

长江机械

行业观点
  • AI装备从情绪修复重回基本面驱动，"卖铲人"逻辑量价齐升：半导体设备、光模块设备、PCB设备三大方向，设备同时具备"量增"和"价升"，技术迭代驱动单机价值量提高、工序增加。
  • 应用材料Q3财季收入超90亿美元同比+25%，下一季指引102.5亿美元，设备需求可见度从几个季度向2年甚至更长延伸，先进封装业务收入增速预期从50%上调至70%以上。
  • 存储扩产从价格周期向资本开支周期传导，AI拉动HBM→DRAM→NAND全产业扩散，存储设备升级为"晶圆产能增长+单位产能设备价值量提升"双驱动。
  • 光模块设备未来需求约3年500亿、5年1000亿市场空间，测试设备最看好量价提升逻辑，800G到1.6T单通道测试速率从100G升至200G。
  • PCB设备Rubin+MSAP双主线拉长景气周期，MSAP 2027年M厂才真正大规模扩产，明后年设备周期有望被明显拉长；SMT回流焊设备升级为潜在新方向。
  • 人形机器人7月回调后具备空间，T链8月底9月初产线安装落地、10月后爬产，9-10月或见V3批量化下线；国产链2026年产销预计10万台以上，宇树等龙头上市催化独立行情。推荐：恒利、绿的谐波、森林之区、北特科技、宇树、优必选。
推荐个股
芯碁微装：先进封装设备第一重点推荐，CoWoS-L智能纠偏LDI国内独家规模化供货，CoPoS配套设备已启动送样，海外客户2026-2027Q1单墨机验证发货。
联讯仪器：光模块测试设备首推，国内唯一可量产1.6T光模块采样示波器，1.6T时代份额预计超50%。
东威科技：PCB电镀设备，M厂高端电镀需求旺盛订单交付紧张，单机价值量相比普通VCP明显提升。
华峰测控 / 长川科技 / 精智达 / 金海通：测试设备第二重点推荐，AI时代"测试通胀"，HBM堆叠层数越高测试次数和精度要求越高。
大族激光 / 英诺激光 / 帝尔激光：MSAP激光钻孔，超快激光导入窗口，日本传统激光设备交付周期长给国产创造导入窗口。

国金证券

行业观点
  • ABF膜：全球市场40-60亿人民币，味之素垄断95%以上份额，计划2032年产能扩至3倍，国产ABF载板2026下半年到2027年有望明确突破，关注生益科技、莲花控股、华正、宏昌电子。
  • 液冷：光模块液冷热管理从壳体外部延伸至模块内部，中际旭创17.47亿入股中石科技10.5%股权锁定上游散热材料；800V HVDC架构带来Busbar液冷、高压连接器、电子屏蔽泵变化，关注金田股份、博威合金、飞龙股份、大元泵业。
  • 北美算力链：SpaceX计划2027年底算力扩大10倍至10GW，英伟达30亿美金投资Lancium锁定电力；Blue Energy Q2收入首破10亿美金，卡特彼勒恢复1.5GW停产产能；冰轮环境AI冷水机组在手订单超90亿，杰瑞股份累计24亿美金燃机订单、7月单月签单近130亿。
  • 锂矿：碳酸锂13.5万阶段性底部确认，7月去库2.1-2.2万吨、8月去库2.8万吨，全行业库存有望降至10万吨以内，现货紧张加剧指引价格往上。
推荐个股
杰瑞股份 / 冰轮环境：北美缺电链核心推荐，订单持续进入兑现期，Q3起之前订单逐步交付，收入利润加速兑现。

中泰机械

行业观点
  • 光模块测试仪器：技术迭代+极速通胀+格局优化三重共振，800G到1.6T单套测试仪器价格从四五十万升至150万，1.6T时代供应商缩圈至是德科技与联讯仪器2家，联讯份额从不足20%升至50%+。
  • 燃气轮机：板块回调始于杀估值而非基本面恶化，GEV/三菱/西门子Q2订单量价产能同步上修，西门子首次明确110-120GW行业需求中枢，供需缺口较Q1扩大约5GW至54-55GW，投资重心从重燃独强转向瓶颈零部件+中燃/航改燃。
  • 机器人：主升浪窗口判断在2026年9-10月，Free Motion工厂一楼全自动化产线8月中下旬到齐、9月中下旬完成安装调试，周产1000台节奏约10月1日前后；筹码结构极干净，核心标的从底部易实现30%反弹。
推荐个股
联讯仪器 / 优利德：光模块测试仪器核心推荐，联讯为全市场跟踪最深，海外订单占一半以上；优利德为二线弹性标的，1.6T采样示波器研发进展存重大预期差。
奕瑞科技：2026H1营收16.7亿+57%，硅基OLED背板第二增长引擎全年收入预计超8亿，RGA半导体质谱仪国产替代窗口期到来，上调盈利预测维持买入，2026/27/28年利润8.26/12/15.56亿。
万泽股份：瓶颈零部件首推，国内唯一高温合金材料到叶片构件全流程民营企业，聚焦中小型燃机叶片，2026年底产能扩至18-19亿，2030年看60亿，高温合金业务2026年实现盈利拐点。
中国动力：主机优先推荐，船舶主业在手订单排至2029年，中材少数股权注入预期+后市场MRO加速增长。
北特科技：机器人核心推荐兼具确定性与弹性，大丝杠+小丝杠价值量最高环节，市值不足200亿。

东吴证券

行业观点
  • 光互联：CPO量产全面落地，英伟达Spectrum-X CPO交换机已全面量产，此前不及预期担忧被证伪；NPO客户评估推进需求提前，传统光模块订单已锁定2026全年下探2027年，2028年已有指引；Q3上游物料与中游模块业绩共振。推荐：中际旭创、新易盛、天孚通信、炬光科技、仕佳光子。
  • 电子：先进封装是Chiplet最强阿尔法方向，通富微电等大规模扩产；模拟芯片成熟制程产能紧缺+涨价周期+DRMOS新大单品；国产算力超节点交换芯片是最佳增量赛道，盛科通信51.2T交换芯片放量。
  • 机械半导体设备：2026年行业前道接近翻倍，2027年前道预期50%以上至翻倍区间，前道核心买确定性；后道8月1日日本出口审批催化加速国产导入。推荐：华创、中微、拓荆、长川、华海清科、迈为。
  • 光模块设备：客户全球化受益海外扩产，耦合与检测两大环节最看好。推荐：罗博特科（耦合）、联讯仪器（测试最推荐）、普源精电、大族数控（PCB钻孔最重点推荐）。
推荐个股
芯碁微装：先进封装核心标的，国内CoWoS-L环节份额100%，COBO带来设备单价翻倍+TAM四倍，海外2026-2027Q1单墨机验证发货，目标市值2000亿以上，当前约600亿。
杰华特：模拟芯片进攻标的，HC低压MOS供应商或已成H7重要供应商，2027年大幅放量，DrMOS需求翻好几倍，弹性与确定性最高。
盛科通信：国产算力超节点交换芯片，国内唯一独立第三方以太网方案厂商，51.2T放量假设拿半份额对应未来市值近3000亿。
联讯仪器：测试环节采样示波器核心标的，单品单价贵、研发设备转量产设备、现阶段全检，业绩有望超预期。
大族数控：PCB设备钻孔环节最重点推荐，逻辑最好确定性最强，海外龙头扩产意愿低利好国产。

  • 先进封装扩产进入上行周期，海外封测订单外溢持续1-2年，后道测试设备供不应求。
  • 估值：头部前道设备公司PS从6月底13-15倍调整至7-8倍，回到相对低位合理区间。

行业观点

  • 研究方法论：从政策驱动到供给驱动，去金融化重塑传导链条；LPR加入后无风险利率向按揭利率传导被钝化；房企从杠杆型ROE向毛利率与周转驱动的精细运营型ROE转型，PB随ROE修复抬升。
推荐个股
建发国际：首推，全行业最佳选择。大股东2026年6月底PB约1倍增持确认中期股价底；24-25年好房子灯塔项目2027年进入结算，减值透彻明年业绩可见；股权激励推出概率较大；当前股息率5.7-5.8%为真实股息率。

华创证券

行业观点
  • Deep Value不能独立构成地产股买入理由：低PB存在合理估值、可证实/证伪性、折价收敛催化剂三大问题；远期ROE决定估值中枢，若长期ROE低于股权回报率合理PB应小于1。
  • 地产股估值修复三阶段框架：第一阶段新增拿地盈利可追踪（中国金茂案例）、第二阶段利润表改善兑现（最值得上仓位，多数公司2027-2028年）、第三阶段利润稳定性验证→估值确定性提升。
  • 催化剂中利润表改善对优秀开发商最为现实，应追踪利润表改善节奏而非折价深度；基于低PB买入却赚到交易的钱若买入逻辑、催化剂、退出条件不自洽，容易在股价过山车中错失机会。
推荐个股
建发国际集团 / 绿城中国 / 华润置地 / 中海宏洋：重点推荐开发类标的，基于布局利润表最快兑现验证而非PB最低。
太古地产：头部购物中心方向，2025年至2026年持续相对看好。
贝壳：2026年稳定收益（赚carry）方向重点关注。

国泰海通

行业观点
  • 1-7月房地产链数据：核心21城销售面积同比+1%、拿地面积同比-24%，首次出现拿地总面积小于销售总面积剪刀差显著，真去库存开启；北京、上海、深圳等重点4-5个城市库存已进入不完全充分状态。
  • 房价：一线城市新房环比连续上涨（5-7月），上海二手房连续5个月环比正增长、同比价格指数约98，按当前趋势4-5个月收回100是大概率事件；2026年四季度行业存量二手房价格同比有望转正。
  • 上市公司中报：盈利端平淡但现金流端明显改善，龙头公司普遍多卖房少拿地经营性现金流明显改好；市场有望重回4000点，蓝筹处于底部修复区间。
  • 房地产为什么是支柱性产业：2024年房地产贷款余额52.8万亿占各项贷款20.6%，土地出让金4.87万亿占地方本级财政收入28.99%，房地产+建筑业增加值合计占GDP接近13%；带动效应呈"消费属性越强、可选性/奢侈性越强带动越明显"，酒店、调味品、区域白酒、金银珠宝、化妆品敏感度高。
推荐个股
华润置地 / 中国金茂 / 中海外发展 / 滨江集团 / 招商蛇口：重点推荐开发类，核心城市去库存拐点确认价格企稳信号渐强，龙头蓝筹进入配置区间。
东方雨虹 / 兔宝宝 / 北新建材 / 三棵树：消费建材龙头格局清晰，中报可见度是短期分水岭。

西部金融地产

  • 2026Q2保险资金运用余额突破40.8万亿同比+12.7%，股票+基金占比达16.2%创历史峰值，但权益仓位上行主要系市场行情上涨带来浮盈增厚而非主动增配，主动增配可能要等到2027年一季度。

兴证地产

行业观点
  • 挂牌量+挂牌去化周期是验证核心城市二手房价格企稳支撑因素的核心跟踪指标；上海挂牌量自2025年4-5月高峰以来下降超30%，挂牌去化周期约6-7个月在核心城市中最优。
  • 刚需价位段进入存量净消耗阶段：新房供应"缩量+提价"偏豪宅化，上海北京500万以内成交占比接近80%，对应刚需价位段新房供给几近消失，刚需只能转向二手房市场。
  • 情绪指标挂牌调涨占比：2026年整体约9较2025年不到5明显改善，若稳定在15以上甚至20以上基本价格端将明显企稳或上涨；上海、北京、苏州、合肥指标相对健康。

中金公司

行业观点
  • 美元流动性三重框架（美联储政策+美债供给+日元套息）研判：静态风险有限、冲击即买点；通胀大概率回落加息并非主要矛盾，三季度美债发行较峰值回落影响介于2023与2025之间。
  • 7月金融数据：居民与企业信贷罕见同时单月负增长，信贷罕见双负增长总量审慎、财政余力是核心变量；降息预期未来12个月具备条件但年内审慎。
  • 北京楼市新政追平沪深，非京籍核心区购房社保降至1年、公积金额度翻倍；剔除房价预期后租售比与融资成本已打平，降息贴息会使购房融资成本低于租房累积观望需求可能入市。
  • 基本面量价均不弱比2025年更好：二手房连续4个月以上同比为正绝对水平比2025年下半年高20%，核心城市房价基本平稳上海连续5个月环比正增长；九月底前是政策博弈密集期。

长江大金融

行业观点
  • 银行：红利资产布局窗口，10年期国债收益率回落至1.69%首次下行突破1.7%，7月新发放企业贷款利率首次跌破3.0%；最优秀头部城商行估值约0.75倍PB距1倍PB仍有30%以上空间，大行A股股息率距3%仍有充裕空间。
  • 房地产：产业政策空间有限，公积金利率为潜在核心变量——5年期以上公贷利率2.6%，公积金额度提升后上海300万以下小房子刺激效果较好（3-7月每月30-40%+成交量正增长），若公积金利率真正调整将是真正的大级别转换政策。

华泰证券

行业观点
  • 存量商业地产迎制度性重估窗口：上海、广州土地续期新政把"届满前一年申请续期"细化为到期续期与提前续期双通道，续期价格不得低于所在区域基准地价的70%。
  • 剩余年限越短的商业地产迎更显著重估机遇：30/20/10年期资产DCF估值较40年期分别降11%/28%/55%，土地续期政策带来的价值重估增量空间分别可达12%/38%/123%。
  • REITs是本轮政策最大边际增量：上海明确拟发行REITs等特殊情形申请年限可根据项目实际情况确定，支持申报后注册前完成续期手续，有望推动REITs扩容。
